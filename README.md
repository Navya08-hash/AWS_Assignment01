# AWS Cloud Computing Assignment

## 1. Create and Configure AWS Account

- Created and configured an AWS account.
- Explored the AWS Management Console.
- Created an IAM user and configured appropriate permissions.

## 2. Explore Core AWS Services

| AWS Service | Function |
|---|---|
| Amazon EC2 | Provides scalable virtual servers for running applications. |
| Amazon S3 | Provides object storage for files and data. |
| Amazon RDS | Provides managed relational databases. |
| AWS Lambda | Runs code without requiring users to manage servers. |

## 3. Mini Project — IAM & S3

### IAM
Created an IAM user with specific permissions for managing the required AWS resources.

### S3
Created an S3 bucket, uploaded static files, and configured the required bucket access/policy settings.

## Conclusion

This assignment provided hands-on experience with AWS account configuration, IAM, S3, and the basic functionality of core AWS services.
